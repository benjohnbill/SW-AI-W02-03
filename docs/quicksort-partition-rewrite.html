03다섯 가지 변화

diff의 조각들은 서로 얽혀 있습니다. 의미 단위로 묶으면 다섯 가지이고, 아래 순서는 서로가 서로를 가능하게 만든 순서입니다.

1

재귀가 함수 안으로 들어왔다

처음 판은 바깥에서 quick_sort_helper를 세 번 부르는 게 전부였습니다. 분할 트리가 깊이 2에서 멈추니, 원소가 다섯 개만 되어도 손이 닿지 않는 구간이 남습니다. [0, 0, 0, 1, 0]이 그대로 반환되던 이유입니다. 함수가 자기 자신을 부르면 트리가 바닥까지 저절로 뻗습니다.
2

종료 조건이 함수 첫 줄에 생겼다

재귀에는 멈출 자리가 필요합니다. start >= end면 즉시 반환하는 한 줄이 그 역할을 합니다. 덤으로 빈 배열도 여기서 걸립니다. 이전에는 검사보다 pivot = arr[n]이 먼저 실행돼서, 검사할 기회 자체가 없었습니다.
3

두 지수가 한 칸 바깥에서 출발한다

i는 start - 1, j는 end + 1. 회전마다 i += 1과 j -= 1을 먼저 실행하기 때문에, 첫 전진이 정확히 양 끝을 짚도록 한 칸 물러선 자리에서 시작합니다.
4

무조건 전진이 반창고를 대체했다

사라진 if arr[i] == arr[j] and i != j: j -= 1은 무한 루프를 막으려고 붙인 줄이었습니다. 값이 피벗과 같으면 두 스캔이 한 발짝도 못 움직이니까요. 이제는 회전마다 두 지수가 강제로 한 칸씩 움직이므로, 막아야 할 무한 루프 자체가 생기지 않습니다. 아래 04가 이 차이를 보여 줍니다.
5

종료 검사가 교환보다 앞으로 왔다

while i < j는 회전이 시작될 때 검사합니다. 교환은 회전 끝에 있으니, 스캔 도중 지수가 교차하면 교환이 먼저 일어나고 검사는 그 뒤에 옵니다. 이미 엉뚱한 자리를 바꿔치기한 뒤죠. 검사를 스캔과 교환 사이로 옮기면서 바깥 루프는 조건을 잃고 while True가 되었고, 탈출은 break가 맡습니다.

04같은 값만 있는 구간에서

[5, 5, 5, 5, 5, 5, 5, 5]을 한 번 분할할 때 두 지수가 어떻게 움직이는지 추적했습니다. 값이 모두 같으니 교환은 아무것도 바꾸지 못하고, 순수하게 지수의 움직임만 남습니다. 중복이 많은 입력에서는 이런 구간이 반드시 생깁니다.

06지금 판에 남아 있는 것

고쳐진 것과 고쳐지지 않은 것을 구분해 둘 필요가 있습니다. 피벗을 구간의 가운데 원소로 고정하는 선택은 그대로입니다. 그래서 [0,1,2,…,2499,2500,…,2,1] 같은 산 모양 배열에서는 지금 판도 깊이 2499가 나옵니다.

다만 이것은 이번 수정과 무관한, 결정론적 피벗 선택 자체의 성질입니다. 무작위 피벗이나 세 값의 중앙값을 쓰면 완화되지만, 분할 로직을 다시 건드릴 필요는 없습니다.

07최종본

quick_sort.py · 검증 통과
def quick_sort(arr):
    start = 0
    end = len(arr) - 1

    def quick_sort_helper(arr, start, end):
        if start >= end:
            return
        i = start - 1
        j = end + 1
        n = (start + end) // 2
        pivot = arr[n]
        while True:
            i += 1
            while arr[i] < pivot:
                i += 1
            j -= 1
            while arr[j] > pivot:
                j -= 1
            if i >= j:
                break
            arr[i], arr[j] = arr[j], arr[i]
        quick_sort_helper(arr, start, j)
        quick_sort_helper(arr, j + 1, end)

    quick_sort_helper(arr, start, end)
    return arr
검증 조건 — 무작위 배열 5,000개(길이 0~9, 값 0~5) 전량 통과. 길이 5,000의 빈 배열·정렬된 배열·역순 배열·전부 같은 값·두 값 교대·완전 무작위 각각 통과, 최대 재귀 깊이 12~28.
